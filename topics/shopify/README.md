Shopify Intelligence Module
Goal: To provide AI Agents (Cursor, Antigravity, Windsurf) with a comprehensive, doc-grounded context for full-stack Shopify development.

How to use:
For IDE Agents: Copy the content of shopify-system-instruction.md into your agent’s system prompt or .cursorrules file.
For Autonomous Agents: Reference these files when initializing agents on Google Cloud Run or via MCP servers.

What's inside:
Architecture: Best practices for GraphQL, Webhooks, and Shopify Flow.
Automation: Logic for autonomous inventory auditing and SEO metadata enrichment.
AIO (AI Optimization): Frameworks for making stores rank in generative search engines.
